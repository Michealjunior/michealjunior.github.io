02 AI evaluation · Python · CI

promptcheck

Regression tests for LLM prompts.

Change a prompt or swap a model and outputs quietly drift: JSON stops parsing, fields vanish, answers start refusing. promptcheck runs YAML test suites against OpenAI, Anthropic or local models, replays recordings for free CI runs, and reports in JUnit, Markdown and HTML.

  • Python
  • PyYAML
  • pytest
  • GitHub Actions
